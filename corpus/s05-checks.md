# Lab verification policy

This is a fictional teaching scenario, not a report about any real server.

## Intended checks
A successful lab check must record its input, expectation and observation. Intended checks cover a valid calculation, rejected invalid input and the public browser journey separately. A planned check is not a passing result. The scenario contains no actual executed outputs.

## Access and unknowns
Import and administration actions are reserved for an authorized operator. Public readers may ask documentation questions. No administrator password, actual server IP address or production outage cause is supplied in these documents.
