# Lab network

This is a fictional teaching scenario, not a report about any real server.

## Shared network
The lab proxy and calculator service are members of the training-proxy network. Within this fictional lab, the proxy reaches the calculator at http://calculator:8000. The application port is 8000 inside the shared network; no public calculator administration port is part of the scenario.

## Scope
A learner should check the source-supported network explanation before proposing any host change. The fictional names are not credentials or commands to run.
