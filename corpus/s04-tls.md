# Lab TLS ownership

This is a fictional teaching scenario, not a report about any real server.

## TLS boundary
The lab design assigns external HTTPS termination to the existing proxy on websecure. The calculator receives HTTP from the proxy across the private shared network. A browser lock or successful HTTPS connection alone does not establish correct arithmetic or correct source citations.

## Limits
The scenario specifies no actual certificate issuer, expiry date or live DNS record. Questions about those values lack supporting evidence.
