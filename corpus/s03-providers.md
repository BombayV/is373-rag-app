# Lab configuration provider

This is a fictional teaching scenario, not a report about any real server.

## Selected provider
The lab scenario enables only a file provider. Its route definition is in a fictional file named calculator.yml. Docker labels are not the configuration source in this scenario. Adding labels alone therefore does not alter this lab route.

## Evidence boundary
A real host could use different providers. A guide answer must not claim to know a visitor's active providers without authorized evidence.
